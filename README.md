# 2024 智能车竞赛气垫船模型

**2024 年第十九届全国大学生智能汽车竞赛气垫组（气垫船组）** 的 SolidWorks 机械结构模型，包括整车装配体、分层底盘、固定件、推进电机与桨叶防护罩、编码测速机构、万向轮机构以及电子元件占位模型。

当前仓库聚焦机械建模与装配设计，不包含控制程序、电路原理图、PCB、完整物料清单或比赛技术报告。

## 赛事背景

- 2024 年赛事为第十九届全国大学生智能汽车竞赛，比赛集中在 7—8 月举行。
- 该届竞速赛设置八个组别，其中气垫组属于自制车模组别，需要参赛队自行完成机械结构、电子系统和控制方案设计。
- 气垫车模在室内 PVC 赛道完成竞速任务；设计需兼顾气垫支撑、推进与转向、赛道循迹以及测速反馈。
- 规则补充说明要求车模不得从弯道内侧越出赛道；测速轮不得提供支撑或驱动力，原则上只能安装一个测速轮。

以上内容用于说明本 CAD 项目的设计背景，不代表本仓库包含完整参赛方案。比赛信息与规则应以组委会最终发布版本为准。

## 快速查看

1. 下载或克隆整个仓库，不要只下载单个装配体文件。
2. 保持 `cad/solidworks/` 内的文件位于同一目录。
3. 使用兼容版本的 SolidWorks 打开 [`cad/solidworks/整车装配体.SLDASM`](cad/solidworks/整车装配体.SLDASM)。
4. 如出现“找不到引用文件”，请在 SolidWorks 中将搜索目录指向 `cad/solidworks/`。

> 原始主装配体使用了内部昵称。公开发布副本已将文件名改为 `整车装配体.SLDASM`，原始工作文件没有被修改。

## 机械设计内容

- 整车与车架：整车装配体、分层底盘、夹层及前后固定杆
- 推进与防护：180 电机、2306 无刷电机、3 寸无刷罩和 3.5 寸固定桨叶座
- 测速机构：编码器、固定板、连接器和编码器轮
- 接地辅助机构：万向轮子装配体、中轴和轴承
- 电子元件占位：电机驱动、电路板、电池及安装底盘
- 标准件：M3 尼龙柱、MF63ZZ 轴承等

## 文件格式与限制

- 原生格式：`.SLDPRT`、`.SLDASM`
- 文件总数：32
- 模型总大小：约 5.1 MiB
- 当前未提供 STEP、STL、工程图、BOM 或渲染图
- 本发布包未在本机 SolidWorks 中重新生成，因此装配约束和引用路径尚未做软件内验证
- 原生 SolidWorks 文件可能保留作者、单位、自定义属性或历史路径；正式公开前建议在 SolidWorks 的文件属性中复核
- 这些模型仅作为设计资料，不应在未经尺寸、公差、材料、强度和安全校核的情况下直接用于制造
